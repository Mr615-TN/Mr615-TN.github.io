SSH Basics

Objective

Log into the game server using SSH on port 2220 with the username bandit0.

Commands Used

  • ssh — Open a secure shell connection to a remote server.

The Walkthrough

To connect to the OverTheWire servers, open your terminal and run:

ssh bandit0@bandit.labs.overthewire.org -p 2220

When prompted for the password, enter the default password: bandit0.

Key Takeaway

Learned how to specify a non-standard port flag (-p) using SSH instead of defaulting to port 22.
